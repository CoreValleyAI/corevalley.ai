# Security

## Reporting a vulnerability

Report it privately through [GitHub's private reporting](https://github.com/CoreValleyAI/corevalley.ai/security/advisories/new),
or email info@corevalley.ai with "Security" in the subject. Please do not open a public issue.

We reply within 5 working days and tell you when the fix ships. Please give us 90 days before
disclosing, and avoid tests that degrade the site for others (load testing, spam through the forms).

## Scope

corevalley.ai, docs.corevalley.ai and status.corevalley.ai, and the code in this repository.
